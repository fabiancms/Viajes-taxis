# Taxi Trips Analysis
# Análisis de Datos - Proyecto TripleTen

🧾 Descripción del proyecto

Este proyecto analiza los datos de viajes de taxis en noviembre de 2017 con el objetivo de identificar patrones de demanda y desempeño de las empresas de transporte.
A través de técnicas de análisis de datos con Python (Pandas, Matplotlib, Seaborn) se estudian métricas como el número total de viajes por empresa y el promedio de viajes por barrio de destino.

El análisis incluye:

🏢 Identificación de las empresas con mayor cantidad de viajes.

📍 Determinación de los barrios con más viajes promedio.

📊 Visualizaciones comparativas para facilitar la interpretación de resultados.

Este proyecto forma parte del aprendizaje en análisis de datos y visualización usando herramientas del ecosistema Python.
